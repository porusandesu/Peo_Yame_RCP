## Account synchronization setup

Both apps store account and crop data in the backend database. Use the web
dashboard's **Connect mobile app** QR to point a physical phone at that same
backend, then use the same farmer phone number in both clients. A backend
running as a separate process or deployment has its own database and accounts.
