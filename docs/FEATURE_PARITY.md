# Feature parity

This fresh implementation targets five matching destinations on web and Android: Overview, Trends, My Crops, Alerts, and Settings. Demo readings and farmer account data are labelled separately. The backend owns status bands and rough estimate calculations. The estimate must include its caveat and a manual crop check reminder.

QR sign-in, authenticator management, session revocation, sensor pairing, SSE updates, export, inspection reminders, and the full Guided demo run sheet remain acceptance items until implemented and demonstrated by Actions evidence. Do not mark them complete based on source presence alone.
