# Peo Yame Android Assets

Copy the `mipmap-*`, `drawable`, and `mipmap-anydpi-v26` folders into your Android project's `app/src/main/res/`.

Recommended manifest:
```xml
<application
    android:icon="@mipmap/ic_launcher"
    android:roundIcon="@mipmap/ic_launcher_round"
    ... />
```

Play Store: use `playstore/icon-512.png`.
